Upload your scan JSON or CSV (from the CLI) to inspect devices and printers.

How to use

  1. Run the CLI locally and save results (JSON or CSV): e.g. python -m net_printer_inspector scan --output ergebnisse.json
  2. Upload the resulting JSON or CSV file here.
  3. Use search and filters to explore, export filtered results if needed.

This viewer does not send any data anywhere — everything runs in your browser.
